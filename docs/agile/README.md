# Agile & QA Documentation

Living project management documents, provided as templates by the internship program and updated as the project progresses.

| File | Purpose |
|---|---|
| `Agile_Template_v0.1.xls` | Product backlog (user stories), sprint backlog, daily stand-ups, sprint retrospectives |
| `Defect_Tracker Template_v0.1.xlsx` | Log of bugs found during development, root cause, and resolution |
| `Unit_Test_Plan_v0.1.xlsx` | Test case documentation — condition tested, expected result, actual result |

These are updated at the end of each sprint/work session to reflect real progress, defects, and testing — not filled in once and left static.
